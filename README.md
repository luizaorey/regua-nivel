# Régua de Nível · Pressão Diferencial

Ferramenta de campo para calcular LRV, URV e span de transmissores de nível
por pressão diferencial, com desenho do arranjo e conferência contra a
medição do programador.

## Arranjos cobertos
- Direto, lado de baixa aberto
- Câmara externa
- Dois selos remotos (capilar nos dois lados)
- Selo direto na alta, capilar na baixa
- Perna úmida com pote de selagem
- Interface entre dois líquidos

## Publicar no GitHub Pages
1. Crie um repositório novo, público, por exemplo `regua-nivel`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Vá em **Settings → Pages**, em *Source* escolha **Deploy from a branch**,
   branch `main`, pasta `/ (root)`, e salve.
4. Em um ou dois minutos o endereço aparece na mesma tela:
   `https://SEU-USUARIO.github.io/regua-nivel/`

## Instalar no iPhone
Abra o endereço no **Safari** (não no app Arquivos, que não executa JavaScript)
→ botão Compartilhar → **Adicionar à Tela de Início**.
O ícone e o nome vêm do `manifest.webmanifest`; o app abre em tela cheia e
continua funcionando sem sinal.

## Onde ficam os vasos salvos
Na memória do próprio navegador, no aparelho. Não sobem para lugar nenhum.
Limpar os dados do site apaga a lista.
